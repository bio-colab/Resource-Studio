# Resource Studio — Visual Identity

## الفكرة المركزية

Resource Studio هو **مختبر بنيوي لملفات PE**: يكشف البنية، يثبت الدليل، ويمنع التغيير غير المقصود. الهوية لا تستخدم رموزًا هجومية أو جماجم أو دروعًا أمنية نمطية؛ بل تجمع بين **عدسة تحليل** و**شبكة PE** و**ورقة دليل** في علامة واحدة هادئة وقابلة للتذكر.

> **Inspect the structure. Preserve the evidence.**

## الشخصية البصرية

الهوية تقنية، دقيقة، هادئة، وذات ثقة مهنية. يجب أن تبدو مناسبة لمطور Windows أو باحث reverse engineering أو هاوٍ يتعلم بنية PE، لا كمنتج مكافحة فيروسات تجاري أو أداة هجومية. كل لون دلالي يجب أن يعكس حالة قابلة للتفسير، لا شدة عاطفية.

| الدور | الاسم | اللون | الاستخدام |
|---|---|---|---|
| خلفية أساسية | Deep Slate | `#101827` | نافذة WPF واللوحات الداكنة |
| سطح | Slate Panel | `#182337` | البطاقات وDataGrid وPreview |
| نص أساسي | Paper | `#F3F7FB` | العناوين والنص عالي التباين |
| نص ثانوي | Mist | `#A9B7C9` | الشروح وmetadata |
| علامة أساسية | Signal Cyan | `#2DD4BF` | الشعار، selection، focus، القيم المثبتة |
| علامة ثانوية | Analysis Blue | `#60A5FA` | الروابط والأزرار الثانوية |
| تحذير | Triage Amber | `#F59E0B` | مؤشرات التحليل التي تحتاج مراجعة |
| خطر بنيوي | Evidence Red | `#EF4444` | corruption أو preservation issue فقط |
| نجاح | Verified Green | `#34D399` | round-trip وvalidation الناجح |

تُستخدم الألوان الدلالية مع نص أو icon أو tooltip، ولا تعتمد على اللون وحده. في الوضع الفاتح تُحافظ الألوان على نفس الدلالة مع أسطح فاتحة، ويظل Signal Cyan هو accent الأساسي.

## العلامة والأيقونة

العلامة الأساسية عبارة عن **مربع PE مجرد** يحتوي مسارًا داخليًا يشبه شجرة بنيوية، مع عدسة صغيرة في الربع العلوي الأيمن. الخطوط مستقيمة ومستديرة قليلًا، والسُمك موحد، ولا توجد كتابة داخل الأيقونة حتى تبقى واضحة عند 16 و24 بكسل.

الأصول المطلوبة هي:

| الأصل | الاستخدام |
|---|---|
| `resource-studio-mark.png` | شعار README وGitHub social preview |
| `resource-studio-icon-256.png` | أيقونة عالية الدقة |
| `resource-studio-icon-64.png` و`resource-studio-icon-32.png` و`resource-studio-icon-16.png` | Windows/WPF وfavicon-like usage |
| `resource-studio-banner.png` | صورة README عريضة، بلا نص مولد داخل الصورة |

يجب أن يكون للعلامة خلفية شفافة أو Deep Slate ثابتة، وألا تحتوي على اسم منتج مولد داخل الصورة؛ يضاف اسم المنتج في XAML وREADME بنص قابل للتحكم.

## قواعد الواجهة

يظهر اسم المنتج بصيغة `Resource Studio` في العنوان، ويظهر الوصف القصير `PE Resource Workbench` في الصف الفرعي أو About view. تستخدم الواجهة Segoe UI أو Segoe UI Variable إن توفرت، وCascadia Mono للـhex وhashes وJSON. لا تُستخدم الخطوط الزخرفية.

الأزرار الأساسية ذات Signal Cyan وتستخدم نصوصًا فعلية مثل `Open PE` و`Inspect` و`Save As`. أزرار destructive مثل `Delete` أو `Strip Signature` تبقى محايدة حتى يمر المستخدم بمسار التأكيد؛ اللون الأحمر محجوز للحالة أو التحذير، وليس لتزيين الأزرار.

## التحقق

يجب أن يظل الشعار والألوان assets فقط. لا تتغير عقود CLI أو Writer أو Verification Engine بسبب الهوية. أي لقطة شاشة منشورة يجب أن تستخدم fixture benign أو واجهة بلا بيانات مستخدم، وألا تعرض مسارات شخصية أو ملفات أصلية محمية.
