# Resource Studio

Resource Studio مشروع مستقل يهدف إلى بناء بيئة حديثة لإدارة موارد Windows وتحليل ملفات PE، مع الحفاظ على نسخة Resource Hacker الأصلية كاعتمادية محلية غير معدلة وعدم إعادة توزيعها ضمن المشروع قبل مراجعة حقوق الاستخدام.

## المبدأ الأساسي

**النواة المستقلة هي الأولوية.** كل وظيفة مهمة في Resource Studio تُبنى أولًا كنواة عملية قابلة للاختبار، ثم يمكن عرضها لاحقًا عبر الواجهة الرسومية وCLI وMCP. بناءً على طلب المستخدم، مسار MCP مؤجل مؤقتًا، ولن تتوسع أدواته أثناء دورة تطوير الإضافات الحالية.

```text
واجهة المستخدم ───────┐
CLI/JSON ──────────────┼──> Core Operations ──> Safe Workspace ──> Verifier
MCP Server (مؤجل) ─────┘              │
                                      ├── Resource Index
                                      ├── PE Read-only Analyzer
                                      └── Optional Resource Hacker Adapter
```

## حدود الإصدار الأول

يركز الإصدار الأول على القراءة والفهرسة والمقارنة، وإنشاء خطط تغييرات، وتنفيذ تعديلات موارد معزولة بعد تأكيد المستخدم. لا يكتب إلى النسخة الأصلية، ولا يعدّل أقسام الكود أو الاستيراد أو التصدير في PE، ولا يحرر PRI مباشرة قبل توفير محلل واختبارات مخصصة.

## واجهة MCP

يوفر الخادم المحلي MCP أدوات قراءة، تخطيط، وتعديل مصنفة بوضوح. أدوات القراءة لا تكتب ملفات. أدوات التخطيط لا تكتب ملفات وتنتج خطة قابلة للمراجعة. أدوات التعديل الحالية محدودة باستبدال raw resource متساوي الحجم داخل نسخة عمل، وتتطلب تأكيدًا بشريًا، وتعيد تقريرًا يتضمن الهاش قبل وبعد، والموارد المتأثرة، والتحذيرات، ونتيجة التحقق. عمليات add/delete وتغيير الحجم ستُضاف عبر backend موارد حقيقي بعد اكتمال اختبارات الأمان.
